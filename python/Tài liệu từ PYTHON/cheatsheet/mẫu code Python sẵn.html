Python Cheatsheet A–Z

26 mẫu code Python cơ bản. Bấm “Sao chép” trên từng thẻ để chép đoạn code, hoặc chép cả bộ một lần. Các lỗi cú pháp trong ảnh gốc đã được sửa nên code chạy được.

A

Arrays (List trong Python)

numbers = [1, 2, 3, 4, 5]   # List có sẵn giá trị
names = [None] * 5          # List kích thước cố định
numbers[0] = 10             # Cập nhật phần tử đầu tiên

List là danh sách có thứ tự, dùng để lưu nhiều giá trị trong một biến và sửa từng phần tử qua chỉ số (bắt đầu từ 0). [None] * 5 tạo sẵn 5 ô trống để điền sau.

B

Basic Syntax – Cú pháp cơ bản

def main():                 # Định nghĩa hàm
    print("Hello, World!")  # In ra màn hình

main()                      # Gọi hàm

Hàm def gom code thành một khối dùng lại được, print() in ra màn hình, gọi main() để chạy khối đó. Đây là khung chương trình nhỏ nhất.

C

Classes & Objects – Lớp và đối tượng

class Car:
    def __init__(self, model, year):  # Hàm khởi tạo
        self.model = model            # Thuộc tính của đối tượng
        self.year = year

my_car = Car("Tesla", 2022)           # Tạo đối tượng

Class là bản thiết kế, object là thực thể tạo ra từ bản thiết kế đó. __init__ chạy khi tạo object để gán dữ liệu cho self. Dùng khi cần gom dữ liệu và hành vi liên quan vào một chỗ.

D

Data Types – Kiểu dữ liệu

n = 10                   # Integer (số nguyên)
price = 99.99            # Float (số thực)
letter = "A"             # Ký tự (thực chất là str dài 1)
is_ok = True             # Boolean
text = "Hello"           # String (chuỗi)
data = {"a": 1, "b": 2}  # Dictionary (từ điển)

Các kiểu dữ liệu cơ bản: số nguyên, số thực, chuỗi, đúng/sai và dict (lưu theo cặp khóa–giá trị). Python tự nhận kiểu, không cần khai báo trước.

Python không có kiểu char riêng: một ký tự vẫn là str.

E

Exceptions – Xử lý ngoại lệ

try:
    x = int("42")                     # Code có thể gây lỗi
except ValueError as e:               # Bắt đúng loại lỗi
    print(e)
else:
    print("Conversion successful")    # Chạy nếu không có lỗi
finally:
    print("Done")                     # Luôn chạy

try/except giúp chương trình không sập khi gặp lỗi. else chạy khi không có lỗi, finally luôn chạy (thường dùng để dọn dẹp, ví dụ đóng file).

F

Functions – Hàm

def add(a, b=0, *args, **kwargs):  # Tham số linh hoạt
    return a + b + sum(args)

result = add(1, 2, 3, 4)           # 1+2+3+4 = 10

Hàm có tham số mặc định (b=0), *args gom thêm các tham số vị trí thành tuple, **kwargs gom tham số đặt tên thành dict. Dùng khi chưa biết trước số lượng đầu vào.

G

Generators

def countdown(n):
    while n > 0:
        yield n            # yield tạm dừng rồi chạy tiếp
        n -= 1

seq = list(countdown(3))   # [3, 2, 1]

Generator tạo giá trị từng cái một khi cần, không dựng cả danh sách trong bộ nhớ. Hợp với dữ liệu lớn hoặc dãy dài vô hạn.

H

Higher-Order & Lambda

squares = list(map(lambda x: x * x, range(5)))          # Áp dụng hàm cho từng phần tử
evens = list(filter(lambda x: x % 2 == 0, range(10)))   # Chỉ giữ số chẵn

map biến đổi từng phần tử, filter giữ lại phần tử thỏa điều kiện, lambda là hàm ngắn không tên viết ngay tại chỗ.

I

Iteration – Vòng lặp với enumerate

for i, v in enumerate(["a", "b", "c"]):  # enumerate cho cả index và giá trị
    print(i, v)

enumerate cho cả chỉ số lẫn giá trị khi duyệt danh sách, khỏi phải tự đếm biến i.

J

JSON

import json

s = json.dumps({"a": 1})   # Chuyển dict thành chuỗi JSON
obj = json.loads(s)        # Chuyển chuỗi JSON về dict

Chuyển qua lại giữa dict Python và chuỗi JSON: dumps để gửi hoặc lưu, loads để đọc lại. Dùng khi làm việc với API hoặc file cấu hình.

K

Keyword Arguments – Tham số đặt tên

def greet(name, *, loud=False):    # Dấu * buộc phải gọi loud=...
    return name.upper() if loud else name

msg = greet("Akash", loud=True)    # "AKASH"

Dấu * buộc các tham số phía sau phải gọi kèm tên (loud=True), giúp lời gọi hàm dễ đọc và tránh truyền nhầm thứ tự.

L

List Comprehensions

pairs = [(x, y) for x in range(3) for y in range(2)]  # Vòng lặp lồng nhau gọn

Tạo list mới chỉ trong một dòng. Ở đây hai vòng for lồng nhau sinh ra mọi cặp (x, y), tổng cộng 6 cặp.

M

Modules

import math as m

m.sqrt(16)   # Dùng hàm từ module → 4.0

Nạp thư viện có sẵn (hoặc file .py khác) để dùng hàm của nó; as m đặt tên ngắn cho tiện gõ. math.sqrt tính căn bậc hai.

N

Namedtuple

from collections import namedtuple

Point = namedtuple("Point", "x y")   # Đối tượng có cấu trúc, nhẹ
p = Point(2, 3)                      # p.x == 2, p.y == 3

Tạo kiểu dữ liệu giống tuple nhưng truy cập bằng tên (p.x) thay vì chỉ số. Nhẹ hơn class đầy đủ và không sửa được sau khi tạo.

O

OOP Inheritance – Kế thừa

class A:
    def speak(self): return "A"

class B(A):
    def speak(self): return "B"   # Ghi đè phương thức của lớp cha

x = B().speak()                   # "B"

Lớp con B thừa hưởng mọi thứ của A và có thể ghi đè phương thức để đổi hành vi. Dùng để tái sử dụng code giữa các lớp có quan hệ với nhau.

P

Paths

from pathlib import Path

p = Path("notes.txt")
exists = p.exists()   # Kiểm tra file có tồn tại không

pathlib xử lý đường dẫn file theo kiểu hướng đối tượng, chạy được trên mọi hệ điều hành. exists() trả về True hoặc False.

Q

Queue – Hàng đợi

from collections import deque

q = deque()
q.append(1); q.append(2)   # Thêm vào hàng đợi
x = q.popleft()            # Lấy phần tử đầu ra → 1

deque là hàng đợi vào trước ra trước (FIFO), thêm và lấy ở hai đầu nhanh hơn list. Dùng để xếp hàng xử lý công việc hoặc duyệt đồ thị theo chiều rộng.

R

Regex

import re

m = re.findall(r"\d+", "a1b22c333")   # Lấy mọi số → ['1', '22', '333']

Regex tìm mẫu trong chuỗi: \d+ khớp dãy chữ số, findall trả về mọi kết quả tìm được. Dùng để trích số, email, ngày tháng... từ văn bản.

S

Sets – Tập hợp

a = {1, 2, 3}
b = {3, 4}
u = a | b   # Hợp (Union): {1, 2, 3, 4}
i = a & b   # Giao (Intersection): {3}

Set là tập hợp không trùng lặp và không có thứ tự. | gộp hai tập, & lấy phần chung. Hợp để loại phần tử trùng và so sánh hai danh sách.

Ảnh gốc viết a bằng ngoặc tròn, nhưng toán tử | và & chỉ dùng được với set nên đã đổi thành ngoặc nhọn.

T

Tuples & Unpacking

t = (1, 2, 3)
a, b, c = t   # Giải nén giá trị

Tuple là dãy không sửa được sau khi tạo. Giải nén gán từng phần tử vào từng biến trong một dòng, cũng là cách để hàm trả về nhiều giá trị.

U

Unit Testing

import unittest

class T(unittest.TestCase):
    def test_add(self):
        self.assertEqual(1 + 1, 2)

unittest.main(argv=[""], exit=False)

Viết test tự động: mỗi hàm test_ kiểm tra một kết quả mong đợi bằng assertEqual. Phần argv=[""], exit=False giúp chạy được trong Jupyter hoặc IDLE mà không thoát chương trình.

V

Variables & Scope – Biến và phạm vi

x = 1

def f():
    x = 2        # Biến cục bộ
    return x

y = f()          # y = 2, x toàn cục vẫn là 1

Biến tạo trong hàm là biến cục bộ: gán x = 2 trong hàm không làm đổi x ở ngoài. Cần hiểu để tránh lỗi trùng tên biến.

W

With (Context Manager)

with open("file.txt", "w") as f:   # Tự động đóng file
    f.write("hello")

with tự đóng file (hoặc giải phóng tài nguyên) khi ra khỏi khối, kể cả khi có lỗi xảy ra. Chế độ "w" ghi đè nội dung file cũ.

X

XML Parsing

import xml.etree.ElementTree as ET

root = ET.fromstring("<a><b>1</b></a>")
value = root.findtext("b")   # Lấy giá trị thẻ → "1"

Đọc dữ liệu XML: fromstring biến chuỗi XML thành cây, findtext lấy nội dung của thẻ con theo tên.

Y

Yield From

def a():
    yield from [1, 2, 3]   # Ủy quyền vòng lặp

out = list(a())            # [1, 2, 3]

yield from chuyển việc sinh giá trị sang một dãy khác, gọn hơn vòng for + yield. Dùng khi ghép các generator lồng nhau.

Z

Zip File Handling

from zipfile import ZipFile

with ZipFile("data.zip", "w") as z:
    z.write("file.txt")    # Thêm file vào zip

Tạo file .zip và thêm file vào. Chế độ "w" tạo mới hoặc ghi đè. Dùng để nén, gộp nhiều file trước khi gửi hoặc lưu trữ.

File file.txt phải tồn tại trong thư mục đang chạy, nếu không sẽ báo FileNotFoundError.

Không có mục nào khớp. Thử từ khóa khác, ví dụ: list, json, lambda.
